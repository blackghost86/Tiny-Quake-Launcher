# Tiny Quake Launcher
A simple launcher for Quake and its mission packs.

# Features
- Runs Quake from your desktop or Quake folder (needs Quake game path).
- Automatic Quake source port detection.
- Automatic episode detection.
- Automatic map detection (from PAK files or custom folders).
- Command line preview based on custom selection.

# Installation
Extract TQLauncher.exe on your desktop or into your Quake directory.

# Prerequisites
Install [.NET 10.0 Desktop Runtime].(https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/10.0.11/windowsdesktop-runtime-10.0.11-win-x64.exe)
