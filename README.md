# Tiny Quake Launcher
A simple launcher for Quake and its mission packs.

# Features
- Runs Quake from your desktop or Quake folder (needs Quake game path)
- Automatic Quake source port detection
- Automatic episode detection
- Quake map PAK detection (including maps in custom folders)
- Automatic map selection for story episodes
- Command-line preview

# Installation
Extract TQLauncher.exe on your desktop or into your Quake directory.

# Prerequisites
.net 10.0 Desktop Runtime
